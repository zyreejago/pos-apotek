1. PENJELASAN NODE
==================

Node 1  : e.preventDefault() - Mencegah reload form saat submit
Node 2  : Memeriksa apakah mode 'add' DAN tidak punya izin 'create'
Node 3  : Jika tidak valid - kirim toast error "Akses Ditolak", proses dihentikan
Node 4  : Memeriksa apakah mode 'edit' DAN tidak punya izin 'edit'
Node 5  : Jika tidak valid - kirim toast error, proses dihentikan
Node 6  : Memeriksa apakah mode 'add', invoice_number terisi, dan invoiceNumberError ada
Node 7  : Jika tidak valid - toast "No. Faktur sudah digunakan", proses dihentikan
Node 8  : Memeriksa apakah mode 'edit' DAN selectedProduct terpilih
Node 9  : Jika valid (edit) - siapkan payload, PUT /products/:id, close, fetch, toast
Node 10 : Jika tidak valid (bukan edit) - masuk blok Add mode
Node 11 : try { - Mulai blok try untuk Add mode
Node 12 : Memeriksa apakah isMultipleProducts true
Node 13 : Jika ya - cek apakah multipleProducts.length === 0
Node 14 : Jika kosong - toast "Daftar produk kosong", proses dihentikan
Node 15 : Loop for setiap item di multipleProducts
Node 16 : Cek apakah item memiliki existingBatchId di perbaikanBatchIds
Node 17 : Jika perbaikan - siapkan FormData, PUT /batches/:id
Node 18 : Cek apakah prodId ada di perbaikanBatchIds
Node 19 : Jika prodId ada - cari produk, refresh jika perlu, PUT /products/:id
Node 20 : Jika item baru - panggil saveProductAndBatch(item) => POST
Node 21 : Kembali ke node 15 (loop next item) atau lanjut ke node 28
Node 22 : Jika false (single) - jalur single product
Node 23 : Cek apakah singleBatchId ada di perbaikanBatchIds['single']
Node 24 : Jika perbaikan single - siapkan FormData, PUT /batches/:id
Node 25 : Cek apakah productId ada di perbaikanBatchIds['productId']
Node 26 : Jika ada - cari produk, refresh jika perlu, PUT /products/:id
Node 27 : Jika single baru - panggil saveProductAndBatch(formData) => POST
Node 28 : handleCloseProductOffCanvas(), fetchProducts(), setPerbaikanBatchIds({}), toast
Node 29 : catch (error) - log error, toast "Gagal menambahkan produk"
Node 30 : Selesai
