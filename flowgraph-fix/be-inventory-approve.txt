Node 18 : Siapkan debit pada journalItems
Node 19 : Cek apakah stock_type == 'lunas'
Node 20 : Cek apakah stock_type == 'dp' dan memiliki dp_amount

Node 28 : finally: release koneksi database ke pool

Node 31 : catch (outer): log error database, return 500 server error
Node 32 : Selesai
