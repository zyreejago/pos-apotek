1. PENJELASAN NODE
==================
Node 1  : Route handler POST /api/returns/sales
Node 2  : Destructure body request (sale_id, refund_method, items, dll)

Node 4  : Cek apakah refund_method valid ('cash' / 'credit_note') -> return 400 jika tidak
Node 5  : Ambil koneksi database dari pool
Node 6  : try { - Mulai blok try utama
Node 7  : Mulai transaksi database (beginTransaction)
Node 8  : Query SELECT transaksi completed berdasarkan sale_id
Node 9  : Cek apakah transaksi ditemukan & completed -> throw Error jika tidak
Node 10 : Ambil detail item transaksi dan grouping berdasarkan produk
Node 11 : Loop items (kondisi loop pertama untuk memproses item retur yang diajukan)
Node 12 : Cek apakah data produk dan qty valid -> throw Error jika tidak
Node 13 : Temukan detail item penjualan produk & hitung sisa kuantitas yang bisa diretur
Node 14 : Cek apakah qty_returned > totalReturnable -> throw Error jika melampaui batas
Node 15 : Alokasikan qty_returned ke batch-batch terkait (FEFO) & kumpulkan ke returnItems
Node 16 : Akhir iterasi loop item retur (kembali ke Node 11)
Node 17 : Generate return number & query INSERT INTO sale_returns header
Node 18 : Loop returnItems (kondisi loop kedua untuk memasukkan data detail & update stok)
Node 19 : Query INSERT INTO sale_return_items detail retur
Node 20 : Cek apakah kondisi barang retur tidak rusak (kondisi !== 'rusak')
Node 21 : Kembalikan stok ke database (UPDATE batches stock & UPDATE products stock)
Node 22 : Akhir iterasi loop update stok (kembali ke Node 18)
Node 23 : Susun journalItems berdasarkan jenis refund (cash/credit_note) dan HPP (Obat/Non-Obat)
Node 24 : Panggil createJournalEntry
Node 25 : Cek apakah transaksi asal sudah sepenuhnya diretur (allFullyReturned)
Node 26 : Query UPDATE transactions (is_fully_returned = TRUE)
Node 27 : Commit transaksi database
Node 28 : Catat audit trail
Node 29 : Return response 201 sukses dengan return_no
Node 30 : catch (err): rollback transaksi database, return response 400 error
Node 31 : Selesai (blok finally release connection dijalankan sebelum selesai)
